# deep-learning-lstm

Language Model zur Wortvorhersage mit einem LSTM Netzwerk auf Basis von TensorFlow.js.

## Quelle der Trainingsdaten

Als Trainingsdaten wurde ein bereinigter Ausschnitt der Bundestagsdrucksache 21/6805 verwendet.

Quelle:

https://dserver.bundestag.de/btd/21/068/2106805.pdf

## Projekt lokal starten

Terminal:

```bash
python3 -m http.server 8000
```

Web:

```
http://localhost:8000/
```
